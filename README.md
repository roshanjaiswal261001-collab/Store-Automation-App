# SmartStore – Store Automation System

## Live Demo

**Live Website:** https://store-automation-app.onrender.com

## Project Description

SmartStore is a web-based Store Automation System developed using React and JavaScript. It helps manage daily store activities through a simple and user-friendly dashboard.

The application provides features for managing products, inventory, billing, customers, suppliers, and sales reports.

## Features

- **Admin Login:** Simple admin authentication.
- **Dashboard:** Overview of store activities and statistics.
- **Product Management:** Add, update, view, and manage products.
- **Inventory Management:** Track stock and stock movements.
- **Billing:** Manage customer bills and sales.
- **Customer Management:** Maintain customer records.
- **Supplier Management:** Manage supplier information.
- **Reports:** View store-related reports.
- **Data Storage:** Uses browser LocalStorage for storing application data.

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/roshanjaiswal261001-collab/Store-Automation-App.git
```

2. Open the project folder:

```bash
cd Store-Automation-App/client
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL shown in the terminal.
